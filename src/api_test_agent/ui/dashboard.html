代码仓库模式 (Git Repository) 源码 AST 静态分析

指定本地只读 Git 仓库快照与多仓版本清单，由适配器执行 AST 语法树解析并识别路由与控制器。

规格来源类型:

直接从运行中的微服务拉取 OpenAPI 3.x 或 Swagger 2.0 规格并建立快照。

被测项目内或本地的 OpenAPI/Swagger JSON 或 YAML 规格文件相对路径。

被测服务的本地 Git 仓库路径。系统通过只读 Git 树提取文件快照。

被测代码的固定提交版本，保障测试证据的确定性与可复现。
